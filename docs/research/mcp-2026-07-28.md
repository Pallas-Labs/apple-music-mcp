# MCP 2026-07-28 modernization notes

Sources are limited to the official MCP specification and official TypeScript SDK.

## Required migration

Before this update, the server used `@modelcontextprotocol/sdk` v1 and connected an `McpServer` directly to `StdioServerTransport`. That path speaks the legacy, initialization-based protocol. MCP 2026-07-28 uses per-request protocol metadata, requires `server/discover`, and has no initialization handshake. The v2 SDK’s `serveStdio(factory)` entry supports the modern protocol and legacy clients from one factory.

Sources: [versioning](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning), [discovery](https://modelcontextprotocol.io/specification/2026-07-28/server/discover), [SDK migration](https://github.com/modelcontextprotocol/typescript-sdk/blob/main/docs/migration/upgrade-to-v2.md), [SDK 2026 support](https://github.com/modelcontextprotocol/typescript-sdk/blob/main/docs/migration/support-2026-07-28.md).

## Decisions

- Use `@modelcontextprotocol/server` v2 and `serveStdio(createServer)`.
- Keep dual-era stdio support so current 2025-era hosts still work.
- Use Zod 4 Standard Schema objects instead of deprecated raw schema shapes.
- Keep output schemas and return both `structuredContent` and serialized text content. The specification requires structured output to match a declared output schema and recommends text content for compatibility.
- Add deterministic tool titles, server website metadata, two read-only resources, and two user-controlled prompts.
- Keep diagnostic logging on stderr. The stdio transport reserves stdout for newline-delimited MCP messages.
- Do not add Tasks, sampling, or elicitation. They do not fit the current short, local Apple Music operations.

Sources: [tools](https://modelcontextprotocol.io/specification/2026-07-28/server/tools), [resources](https://modelcontextprotocol.io/specification/2026-07-28/server/resources), [prompts](https://modelcontextprotocol.io/specification/2026-07-28/server/prompts), [stdio](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/stdio), [SDK tools](https://github.com/modelcontextprotocol/typescript-sdk/blob/main/docs/servers/tools.md).

## Follow-up opportunity

Bulk AppleScript operations have timeouts but do not yet stop their child process when an MCP request is cancelled. A later change should thread the request abort signal through tool handlers into `runAppleScript`, then add cancellation tests. Progress notifications may help long library scans, but should only be emitted when the caller supplies a progress token.

Sources: [cancellation](https://modelcontextprotocol.io/specification/2026-07-28/basic/patterns/cancellation), [progress](https://modelcontextprotocol.io/specification/2026-07-28/basic/patterns/progress).
